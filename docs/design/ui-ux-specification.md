# UI/UX Specification

## Direction
Cinematic, modern, fast, mobile-native and social. A dark-first direction is preferred for the initial concept, subject to Phase 1 research.

## Primary navigation
Initial proposal: Discover, Feed, Library, People, Profile.

## Signature component
The Movie Card is the primary interaction surface. It should communicate poster/backdrop, title, year, rating, key genres and optional compatibility.

## Interaction
- Right swipe: Like.
- Left swipe: Pass.
- Save: Wishlist.
- Tap: Movie details.

Use native-feeling animation and haptics where appropriate.

## Required states
Every major screen defines loading, empty, error and success states.

## Design research
Mobbin is reference material for mobile patterns, not a source to copy directly.

## Accessibility
Use adequate contrast, practical dynamic text support, appropriate Android touch targets, non-color-only meaning, and reduced-motion support where practical.
