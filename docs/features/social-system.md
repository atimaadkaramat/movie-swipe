# Social System

## Goal
Create a social layer around movie taste without turning the app into a generic social network.

## Features
Profiles, follow/unfollow, followers/following, activity feed and following feed.

## Activity examples
- User liked a movie.
- User added a movie to wishlist.
- User rated a movie.
- User reviewed a movie.
- User created a public list.

## Privacy
Users control what activity is visible.

## Future
Comments, recommendations to friends, taste compatibility, Movie Twin and group movie nights.
