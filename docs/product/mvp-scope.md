# MVP Scope

## In scope
Authentication, onboarding, movie discovery, swipe actions, movie details, Library, basic ratings, Supabase data, TMDB data.

## Out of scope
Advanced collaborative filtering, Movie Twin, reviews/comments, public lists, group movie nights, push notifications, complex analytics, AI recommendations, streaming integrations.

## MVP exit condition
The complete personal discovery loop works on a real Android device without requiring any Radix Automations service.
