# Product Requirements

## Vision
Help people discover movies they are likely to love by combining personal behavior, movie metadata, recommendations, and people with similar taste.

## Core loop
Discover → Swipe → Like/Pass/Save → Watch → Rate → Build taste profile → Better recommendations → Follow similar people → Discover again.

## Core actions
- Like
- Pass
- Wishlist
- Watched
- Rate

## Social value
Users can follow people, see relevant activity, discover similar taste, compare movie taste, find a Movie Twin, and eventually collaborate on movie nights.

## Target audience
Android users who regularly watch movies and enjoy discovery and social recommendations.

## Principles
1. Fast discovery.
2. Minimal friction.
3. Strong visual presentation.
4. Useful personalization.
5. Social discovery without excessive noise.
6. Privacy by default.
7. Free-first infrastructure.
8. Mobile-native interactions.

## MVP non-goals
- Streaming movies.
- Hosting copyrighted movie files.
- Full-scale chat.
- Complex AI recommendation infrastructure.
- Paid subscriptions.
- Large media storage.
- Microservice architecture.

## MVP success criteria
A user can register, complete onboarding, discover movies, swipe, like/pass/save, open details, see Library results, and return later with history intact.
