# Integrations

## Supabase
Database, authentication, realtime and RLS. Must be a dedicated MovieSwipe project and never the Radix infrastructure.

## TMDB
Movie metadata, search, discovery, cast/crew, genres and similar movies. Credentials must follow current TMDB requirements.

## Resend
Verification/support email and optional future recommendation/social emails.

## GitHub
Source control, issues and project history. Repository: atimaadkaramat/movie-swipe.

## Mobbin
UI/UX pattern research.

## Replit
Optional development/prototyping. GitHub remains source of truth.

## Context7
Current documentation for rapidly changing libraries.

## PostHog
Product analytics and experiments. Deferred until core MVP works.

## Expo/EAS
Android development builds and production APK/AAB workflow.

## Vercel
Optional supporting web/server functionality only.
